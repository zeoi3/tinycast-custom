## 2. 功能边界

### 保留

- 应用模糊搜索与启动，现有中文/拼音和别名检索基础。
- 全局面板唤起、按应用快捷键，已有收藏等轻量应用操作。
- 计算器数学运算及相关复制/历史能力；不新增计算功能，关闭汇率/加密货币联网功能。
- 快速链接：URL、搜索、文件、深度链接及输入/当前剪贴板/日期占位符。
- Apple 快捷指令：搜索、执行、别名与全局快捷键。
- 命名 shell 命令：搜索、执行、快捷键及必要错误反馈。
- 设置备份与导入、现有 Raycast 配置导入；只恢复产品允许的设置和数据。
- 基础设置、开机启动、权限提示、关于、退出等必要管理入口。

### 首版停用

剪贴板历史、片段、文件搜索、字典、笔记、日历/会议、窗口管理、额外窗口/菜单导航、
表情、听写、摄像头、额外系统工具、内置 AI 聊天及账户/MCP、AI 快捷操作、Raycast 扩展运行时。
赞助提醒及与原项目运营有关的推广入口不出现在日常使用流程中；上游署名和许可证保留。

“停用”必须覆盖界面、设置搜索、命令索引、热键、深度链接、服务启动、后台任务和配置恢复。
不默认删除用户已有历史数据，不全盘删除共享工具；关闭剪贴板历史仍允许快速链接读取当前剪贴板、正常复制结果。

## 4. 关键实现规则

### 统一功能范围

有效启用状态 = 产品允许该功能 AND 用户开启该功能。
范围定义集中管理，沿用现有模块和协调器；新版本/旧备份里的未知能力不自动开放。
设置页不展示大量置灰开关；只展示首版需要的配置。计算器、热键等优先保留已有设置位置。

审查配置导入中的能力开关、启动监听的权限、别名/热键和导入数据类别，防止“界面没有但后台已启动”。
禁用的历史/扩展数据不导入本版运行存储；必要时告知跳过的类别，不静默恢复全部内容。

### 独立身份

现有 AppPaths 对未知 Bundle ID 有独立路径回退，复用并验证，不额外改写存储体系。
检查深度链接注册：独立自定义 scheme，保留快速链接打开外部应用能力，不争用官方应用和 Raycast 的 scheme。
开发版和交付版各自隔离；不自动复制官方版设置，用户可以显式导入允许的数据。
全局快捷键由用户设置；两版同时运行时明确处理冲突，不默认抢占官方版按键。

### 网页 AI 的首版交互

- 默认网站 ChatGPT；可选择已配置网站、添加或编辑自定义网址/搜索模板。
- 从面板输入问题并运行网页 AI 命令，使用默认浏览器。
- 有经过验证的输入预填方式时才使用；不假设网站有稳定的 URL 参数或自动发送接口。
- 通用可用路径是“复制问题并打开网站”，以中文提示“问题已复制，请粘贴发送”；不将此描述为已经开始对话。
- 不做浏览器注入、自动登录、模拟点击发送、多轮聊天或本地聊天记录。
- 读取剪贴板只在用户明确执行相应快速链接占位符时发生，不恢复剪贴板历史监听。

### 中文化

只翻译用户可见内容，不改稳定 ID、配置键和备份格式。
设置搜索使用稳定定位标识，中文标题和英文别名都可以找到同一行；不能让翻译破坏滚动定位。
第三方应用名、用户自定义命令名/脚本和网站内容不强行翻译。
未保留的模块不做整套汉化；必要共享提示仍覆盖。

### 内存目标

先测冷启动完成后、空闲、面板打开/关闭循环后的内存与 CPU；两版使用相同配置与数据，分别运行比较。
按需清理无用常驻对象，不重写整个 AppCore。系统分配器可能不立即归还内存，因此同时检查后台活动和多轮稳定性。
没有数据前不承诺节省百分比，也不以源码/安装包体积直接推导运行内存。

## 5. 验收清单

| 场景 | 预期 |
| --- | --- |
| 中文、英文、拼音查应用 | 找到并打开正确应用；中文输入法退格/回车不误触发命令 |
| 全局唤起、关闭、切回原应用 | 焦点与快捷键正确；按应用快捷键仍有效 |
| 数学表达式、复制结果 | 与基线一致，错误有反馈；无汇率后台请求 |
| 快速链接参数/当前剪贴板/日期 | 正确解析和打开；关闭历史不影响当前剪贴板占位符 |
| Apple 快捷指令、自定义 shell 命令 | 面板与热键两条路径均工作；用无破坏性的验证命令 |
| 设置搜索 | 中文词和英文别名都能定位正确设置行 |
| 备份导出后导入 | 保留配置恢复；禁用功能、监听和历史不被重新打开 |
| 旧热键、深度链接、settings.json | 不能绕过产品范围触发关闭模块 |
| 网页 AI | 默认 ChatGPT；切换/自定义网站有效；通用复制打开流程提示准确 |
| 并存与重启 | 不覆盖官方数据，不抢占协议；登录项、设置和用户授权符合定制身份 |
| 空闲和多次开关面板 | 无关闭模块的后台活动；记录真实内存/CPU和是否持续增长 |
| 最终安装包 | 挂载 DMG、拷贝 App、启动、唤起面板；架构/版本/签名/校验和一致 |

自动检查按 `docs/testing.md` 执行；已有失败单列并判断影响，不用跳过失败来宣称全绿。
外部应用权限、浏览器登录态等无法自动验证的步骤，保留简短的用户确认清单。
